# Foodcom-Recipe-Popularity-Analysis

This project explores **why some dishes become popular on Food.com** while others go unnoticed — using data from **over 500 K recipes** and **1.4 M user reviews**.  
Through data cleaning, visualization, and analysis, we reveal the key factors behind recipe popularity and user satisfaction.


## Objectives
1. Identify which recipe features most influence **ratings** and **popularity**.  
2. Compare **visibility (number of reviews)** and **satisfaction (average rating)** to separate exposure from true preference.  
3. Provide **data-driven insights** for food platforms and content creators.


## Methods
- **Data Source:** Food.com Kaggle dataset (recipes + reviews)  
- **Data Cleaning:** handled missing values, removed duplicates, renamed columns, merged recipe/review datasets  
- **Feature Engineering:** created metrics for popularity, average rating, ingredient counts, and cooking time bins  
- **EDA & Visualization:**  
  - Trend analysis (2000–2020)  
  - Ingredient distribution & complexity  
  - Nutritional correlation heatmaps  
  - Sentiment cues from recipe titles  
  - Popularity vs rating relationship  
- **Tools:** Python (pandas, seaborn, matplotlib, numpy, scikit-learn)


## Key Findings
1. **Popularity ≠ Satisfaction** — Heavily reviewed recipes often have average ratings; visibility attracts diverse opinions.  
2. **Simplicity wins** — Recipes with 6–9 ingredients and moderate cooking time earn higher ratings.  
3. **Balanced nutrition matters** — Moderate calories and protein-fat balance relate to better feedback.  
4. **Words sell flavor** — Descriptors like “garlic,” “crispy,” and “fresh” boost user interest and ratings.  
5. **Platform maturity stabilizes ratings** — As user base grows, collective taste becomes clearer and more consistent.

## Insights & Implications
Our analysis highlights that **visibility and satisfaction are distinct dynamics**.  
For recipe platforms and content creators, this means:
- Optimize for **clarity and ingredient simplicity**.  
- Use **familiar flavor words** to trigger engagement.  
- Promote **balanced and sustainable recipes** that align with modern health values.
